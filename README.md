# Godspeed War Room

Dependency-free static team race-planning website for Vercel.

## Deploy to Vercel

Recommended settings:

- Framework Preset: Other
- Root Directory: blank/default
- Install Command: npm ci
- Build Command: npm run build
- Output Directory: public

The actual website files are in `/public` so this works even if Vercel is configured to expect a `public` output directory.
